# 11月国家公园环线行程（ChatGPT 原始规划）

来源：https://chatgpt.com/s/t_6a7a889c2ae08191be32b672b9733b0e
硬约束：11/11 晚抵达 LAX，11/19 必须回 LA（婚礼），11/22 23:00 LAX 起飞
路线：LA → Page/Antelope → Moab → Canyonlands → Arches → Capitol Reef → Bryce → Zion → Las Vegas/Sphere → LA → Joshua Tree → San Diego → LA

## 逐日明细

### Day 1 | 11/12 Thu | LA → Page, AZ
- 07:00 出发，约 8–9h，全天赶路
- 路线：LA → I-15 → Las Vegas 外围 → St. George → Kanab → Page
- 16:00–16:30 前到 Page 则去 Horseshoe Bend（1.5 miles round trip，轻松）
- 住宿：Page

### Day 2 | 11/13 Fri | Lower Antelope Canyon → Moab
- 上午 Lower Antelope Canyon：08:15 到，09:00 tour，10:30–11:00 出来
- Navajo Nation：必须 guided tour，另收每人每天每区域 $15 entry fee
- 下午 Page → Moab 约 4.5–5h
- Option B（可选）：绕 Monument Valley（天气好+时间够才去，非硬任务）
- 住宿：Moab（住两晚）

### Day 3 | 11/14 Sat | Canyonlands + Arches
- 07:00 Moab 出发，约 45min 到 Canyonlands Island in the Sky（不要去 Needles）
- Mesa Arch → Grand View Point（1.8 miles trail 可选）→ Green River Overlook
- 13:00–13:30 进 Arches（2026 不需要 timed-entry）
- Scenic Drive：Park Avenue → Balanced Rock → Windows Section（North/South Window + Turret Arch）→ Double Arch
- 夕阳 Delicate Arch：14:45–15:00 开始 hike（3 miles round trip，带 headlamp/保暖层）
- 住宿：Moab

### Day 4 | 11/15 Sun | Arches 上午 → Capitol Reef
- 早上补 Devils Garden：Landscape Arch（1.9 miles round trip）→ Sand Dune Arch → Skyline Arch
- 11:00–12:00 离开 Moab → Capitol Reef 约 2.5h
- 下午：Fruita Historic District → Petroglyphs → Hickman Bridge（1.8 miles，时间不够可不走）
- Capitol Reef Scenic Drive（主路 7.9 miles 铺装）
- Sunset：Sunset Point / Goosenecks Overlook
- 住宿：Torrey

### Day 5 | 11/16 Mon | Capitol Reef → Scenic Byway 12 → Bryce
- 早上可补 Hickman Bridge 或 Grand Wash
- 走 UT-12 Scenic Byway：Torrey → Boulder → Escalante → Bryce（不要走高速）
- 途经：Boulder Mountain、Grand Staircase–Escalante、Hogback
- 14:00–15:00 到 Bryce：Sunrise Point → Sunset Point → Inspiration Point → Bryce Point（道路开放时）
- Sunset 选 Sunset Point
- 住宿：Bryce Canyon City / Ruby's Inn

### Day 6 | 11/17 Tue | Bryce → Zion
- 早起 Sunrise Point 看日出
- Navajo Loop + Queen's Garden（约 3 miles，Bryce 必做；11 月可能结冰，microspikes 必须带，结冰不硬走）
- 中午 Bryce → Zion 约 2h，从 East Entrance 进
- 途经 Checkerboard Mesa → Zion–Mount Carmel Highway → 穿 tunnel
- 下午 Springdale 入住；时间允许走 Canyon Overlook Trail（~1 mile round trip）
- 住宿：Springdale

### Day 7 | 11/18 Wed | Zion → Las Vegas Sphere → LA
- 上午 Zion Canyon shuttle（2026 年运营到 11/28，首班约 7:00，Visitor Center 末班约 17:00；不能自驾进 canyon）
- 走 The Narrows Riverside Walk（不涉水）；体力好可到 Scout Lookout（不做完整 Angels Landing，需要 permit）
- 11:30–12:00 离开 Zion → Las Vegas 约 2.5h，14:30–15:00 到
- 吃饭 + Sphere 大球（外面看 30–60 min；The Wizard of Oz at Sphere 约 75 min，需提前确认 11/18 场次）
- 18:00 Vegas → LA 约 4–4.5h，22:00–23:00 到 LA
- 住宿：LA（婚礼前夜）

### Day 8 | 11/19 Thu | LA 婚礼
- 不安排旅游

### Day 9 | 11/20 Fri | LA → Joshua Tree → San Diego
- 07:30–08:00 出发，约 2.5h 到 Joshua Tree West Entrance
- 穿越路线：West Entrance → Hidden Valley（1 mile loop）→ Keys View → Skull Rock → Cholla Cactus Garden → Cottonwood Exit
- 可选 Barker Dam
- 从 Cottonwood 南口出 → San Diego 约 2.5–3h
- 住宿：San Diego Little Italy；晚上 Little Italy 吃饭 + Waterfront

### Day 10 | 11/21 Sat | San Diego 全天
- 上午：La Jolla Cove（海狮海豹）→ Torrey Pines（Guy Fleming Trail 或 Razor Point）
- 下午：Balboa Park（建筑花园，不用进很多 museum）
- 晚上：Coronado（Hotel del Coronado + 海滩）→ Little Italy / Gaslamp 吃饭
- 住宿：San Diego

### Day 11 | 11/22 Sun | San Diego → LA → LAX 23:00 航班
- 上午 brunch；可选 Cabrillo National Monument 或 USS Midway（二选一）
- 14:00 左右离开 San Diego，2–2.5h
- 目标 18:00 到 LAX 区域：加油 → 还车 → shuttle
- 国际航班 19:30 前到 terminal；23:00 起飞
